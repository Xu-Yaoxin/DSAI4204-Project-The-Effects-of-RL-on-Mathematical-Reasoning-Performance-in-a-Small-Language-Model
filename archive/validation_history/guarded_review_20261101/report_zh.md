# 2026-11-01 基线能力边界复核

**MATH Level 4 的标量、无图子集更符合本次选材目标。** 在固定的五分钟限时与重复停止规则下，Qwen3.5-2B-Base 的成功率为 175/400 = **43.75%**；GSM-Symbolic main 为 256/400 = **64.00%**。建议保留 2B 模型，以 MATH Level 4 作为下一轮主实验候选，GSM main 用作较容易的对照。

这是只测 Base 的难度校准，尚未比较 RL 模型，不能从本轮结果推断训练增益或证明能力边界已经扩大。

| 指标 | GSM-Symbolic main | MATH Level 4 |
|---|---:|---:|
| 题数 × 每题采样 | 100 × 4 | 100 × 4 |
| 确认正确 / 全部回答 | 256 / 400 | 175 / 400 |
| 全部请求中的成功率 | 64.00% | 43.75% |
| 95% 家族聚类 bootstrap 区间 | 55.24%–72.66% | 36.99%–50.75% |
| 自然结束 EOS | 398（99.50%） | 338（84.50%） |
| 自然结束回答中的正确率 | 64.32% | 51.78% |
| 五分钟超时，按协议计错 | 0 | 33 |
| 重复停止，数学正确性未知 | 2 | 29 |
| 四次中至少一次成功的题目 | 85 / 100 | 68 / 100 |

这里的主要指标把所有请求都计入分母：例如 MATH 的 175 个确认正确回答除以 400，而不是只除以 338 个自然结束回答。超时计零分；重复停止不获得成功分，但不声称其数学答案必然错误。如果给 29 个未知重复结果分别赋零或一，MATH 的诊断范围为 43.75%–51.00%，这不是置信区间，也不等于取消保护后的预测成绩。

MATH 的点估计符合 40%–50% 目标，但 95% 区间仍跨越这个范围，不能宣称总体正确率已精确落在目标内。GSM 的两个重复未知项即使都补计成功也只会把 64.00% 提到 64.50%，不会改变它相对偏容易的判断。每题四次回答不是四道独立题：GSM 的 100 题来自 64 个模板家族，统计按家族重采样；MATH 此次有 100 个问题家族。

MATH 100 题中，32 题四次均未成功、49 题成功 1–3 次、19 题四次全成功。49 道中间状态的题说明样本整体存在成功概率改善的空间；32 道零成功题仍可能奖励稀疏。四次零成功不能证明模型完全不会，更不能据此保证 GRPO 训练后一定能学会。不要从这 49 题中直接挑选正式测试集，以免按观察结果筛选造成偏差。

这些是事后小样本诊断。Geometry 仅 5 题，不能因刚好达到 50% 就单独选它。下一轮应预先固定来源、标量/无图过滤与科目抽样比例，再抽取新题；本轮数据保留为校准集。训练题应来自官方 train，开发和正式测试要独立，并排除已经用于筛选的题目及可识别模板家族。当前结论只覆盖这个子集，不代表整个 MATH 或所有 Level 4 问题。

运行保护在真实 4090 上已得到证据支持。总墙钟时间为 **5 小时 7 分 37 秒**；worker 0 结束后才启动 worker 1，两个进程均正常退出，自动重启为零。33 次超时都在 **300.110–300.146 秒**结束，每次生成约 11,849–12,327 tokens；没有触及原生上下文上限。64 次超时/重复停止仅占回答的 8%，却占逐回答时间的 **64.00%**，其中超时单独占 **53.94%**。长输出是主要时间消耗。

逐项核对了全部 800 个 token 轨迹，共 733,721 个生成 tokens，与保存样本完全一致。31 个重复停止也通过冻结检测器重放。抽查发现有的超时回答并非空白占位符：`math-l4-confirm-algebra-0991 / sample 2` 已算出正确的 81，却不断重复题目和解答；按本轮规则仍应计零。另一些输出包含有用推导，但在算术纠正中循环。不能把所有超时都解释成完全不具备数学知识，也不能为个别提前出现的正确数字追溯改分。没有发生强制退出和自动重启，因此真实 GPU 下的该恢复分支本轮仍未被触发验证。

判分审查覆盖了全部 **45 条自然结束但提取失败/答案歧义的记录**，不是全部 800 条数学推导的人工认证。发现 GSM 有 5 条、MATH 有 4 条明确的正确数值因格式被拒绝。例如 `math-l4-confirm-algebra-0667 / sample 1` 输出正确 `4/13` 后，在说明句中再次出现 “The final answer…” 而导致提取失败。只补计这类明确格式案例，事后敏感性成功率为 GSM **65.25%**、MATH **44.75%**，选材判断不变。

MATH 另有 7 条最终自我纠正正确但此前给过冲突答案，以及 1 条推导得到精确分数而最终输出近似小数。若进一步接受这些，敏感性结果依次为 46.50% 与 46.75%；这涉及评分政策选择，不应全部称为程序错误。官方 43.75% 保持不变。后续比较前应统一修复明确的格式误解析、确定自我纠正和小数容差规则，再对 Base/RL 使用同一冻结判分器。

还发现一条 GSM 来源措辞问题：`gsm-main-confirm-1207-41` 说有 6 条鱼，只列出第一、第二、最后一条的重量，标准答案却隐含其他鱼都与最后一条等重；四个回答都只相加明确给出的三项。这一题需要来源审查，不宜直接作为明确的模型算术失败。未因此修改本轮分数。
