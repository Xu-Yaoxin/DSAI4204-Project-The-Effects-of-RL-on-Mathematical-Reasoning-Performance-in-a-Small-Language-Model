# 2B 与 4B 的实验适配判断

日期：2026-10-30。范围：研究设计审查，不含 4B GPU 运行或模型质量实测。

建议保留 2B 作为主实验；4B 在技术预检通过、预算允许时作为模型规模对照。当前证据不能证明哪个规模更容易得到支持假设的结果。选择依据应是检验是否充分，而不是预期结果是否符合假设。

## 已核对的研究问题

原始 `project/DSAI4207_LLM_Proposal_Overleaf(4).pdf` 第 1 页、第 1 节将主假设写为：

\[
\Delta_k=\operatorname{pass@k}_{\mathrm{RL}}-\operatorname{pass@k}_{\mathrm{Base}},\qquad
\Delta_1>0,\qquad \Delta_1>\Delta_{16}.
\]

第 2 页、第 3 节还要求比较数值变体与关系变体上的 RL 增益。项目同时记录 both、base_only、rl_only、neither 四种题目覆盖集合。最多 16 次采样只能描述有限采样覆盖，不能确立绝对推理边界。

第 2 页、第 4 节允许根据资源和 pilot 调整初始方案，但要求在正式测试前确定，不能按测试表现选择设置。当前 2B 实验已开始，应保留并报告其结果，包括不支持假设的结果。

## 为什么暂时以 2B 为主

用户最新两步日志的奖励为 0.2812 和 0.1875，约为每步 32 个回答中 9 个、6 个正确。零奖励标准差的题组比例分别为 0 和 0.25，即这两步中 4 道题、3 道题有正负奖励差异。有限非零梯度也存在。这些日志说明 2B 当前没有陷入所有题组全错、完全没有奖励差异的状态；它们不证明独立题目上的准确率或训练收益。

2B 的完整训练已经可运行，而 4B 的实际训练速度尚未测量。在固定 GPU 时间下，更高吞吐可以支持更充分的评测、预先规定的较高采样预算或独立训练种子。对本项目而言，这些证据与新增一个模型规模同样需要预算。仅有一个训练种子时，按题 bootstrap 的置信区间不包含训练随机性。

工程 baseline 使用训练子集，不能作为独立开发集上的模型选择证据。当前没有两种规模在相同开发题目上的 Base pass@1/pass@16、截断率和耗时比较，因此没有质量证据要求把主模型换成 4B。

## 更大模型可能带来的混淆

若 4B 在 GSM8K 或简单结构题上的 Base pass@16 已接近 100%，则该指标可上升的空间很小。此时正的 pass@1 增益更容易大于 pass@16 增益，但这种现象本身对机制的解释力有限。4B 是否实际存在此天花板效应，仍需开发集测量。

以下为独立同分布采样的理想化概率计算，既不是 2B/4B 实测，也不假定所有真实题目难度相同。对于单道题，单次正确概率为 p 时：

\[
P(\text{16 次全部失败})=(1-p)^{16},\qquad
P(\text{16 次至少成功一次})=1-(1-p)^{16}.
\]

| 假设的单次成功率变化 | 单次增益 | 16 次覆盖变化 | 16 次覆盖增益 |
|---|---:|---:|---:|
| 10% 到 20% | 10 个百分点 | 81.4698% 到 97.1853% | 15.7155 个百分点 |
| 40% 到 50% | 10 个百分点 | 99.9718% 到 99.9985% | 0.0267 个百分点 |

两个例子都只提高了原先非零的成功概率，覆盖指标的增益次序却不同。因此，端点增益的大小必须结合 Base 水平、整条 pass@k 曲线、逐题覆盖变化以及输出诊断解释。不能把端点关系直接等同于新推理能力是否产生。

2B 也可能过弱：如果在独立开发集上几乎没有正确回答、训练持续缺乏混合奖励、结构变体几乎全部失败，则较强底座更适合研究可观察的训练变化。当前几条训练日志未显示这种完全的学习下限，但不能替代开发集评估。

## 4B 的下一步定位

技术预检通过后，在相同且未参与训练的开发题目上比较 2B Base 与 4B Base 的 pass@1/pass@16、正确回答分布、格式与截断情况、采样耗时。预先固定检查范围和决定规则，保持正式测试集独立。若 2B 有足够学习信号且评测未严重受地板效应影响，继续以 2B 为主；若 2B 的学习下限使问题无法测量，再考虑将 4B 设为新主实验，并记录原因。

有预算时，比较 2B Base 与 2B RL、4B Base 与 4B RL 两组内部差值，再分析规模差异。直接比较 2B RL 与 4B Base 不能隔离 RLVR 的作用。两组应共享数据划分、提示、评分、采样预算及精度；相同训练题数和更新次数并不意味着相同计算预算，须同时报告 GPU 小时。

## 外部来源核对

Yue et al. (2025), *Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?*, v5：https://arxiv.org/html/2504.13837v5 。其第 4.6 节研究更大规模模型，第 A.2 节说明多个主要评测使用 128、256 或 1024 次采样。本文的 2B/4B、16 次采样方案属于较小规模的概念复现。上面的模型选择建议和概率例子是针对本项目的分析，不是原论文关于 Qwen3.5-2B 与 4B 的实验结论。
