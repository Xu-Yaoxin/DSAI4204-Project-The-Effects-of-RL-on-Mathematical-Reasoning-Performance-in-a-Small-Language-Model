# 本轮结果的推断边界与后续顺序

日期：2026-10-31。范围：下载结果的研究设计解释；不修改原始报告、评分器、检查点选择或云端进程。

## 当前可以报告的结果

按本轮实际使用的评分协议，200 道测试题、每题每模型 16 个回答显示：Base pass@1 为 45.34375%，RL 为 79.0625%，增加 33.71875 个百分点；对应按题配对 bootstrap 的边际 95% 区间为 30.75 至 36.65625 个百分点。

Base pass@16 为 94%，RL 为 95.5%，增加 1.5 个百分点；区间为 -1 至 4 个百分点。两组均覆盖 186 道题，仅 Base 覆盖 2 道，仅 RL 覆盖 5 道，两组均未覆盖 7 道。因此观察到的是 188 道到 191 道的有限采样覆盖变化，不能报告“覆盖缩小”，也不能因区间跨零而报告“覆盖完全没有变化”。

两个增益之差为 32.21875 个百分点，区间为 28.12421875 至 35.8453125 个百分点。原始评分下的数值关系符合 proposal 的操作性假设：单次增益为正，且大于 16 次采样增益。它还不足以确立“RLVR 没有新增推理能力”的机制结论。

## 两个关键解释限制

首先，已发现实际提取错误，而不只是模型未遵守格式。类似 `Answer: #### 5` 的回答会同时产生有效的标记答案 `5` 和无效的重复候选 `#### 5`，后者否决前者。原始报告仍需保留；针对明确解析错误的对称重评分，应另列为事后敏感性分析并记录规则与版本。

父代理转来的窄范围复核结果为：只排除这类重复候选时，Base 正确回答从 1,451 条增至 1,885 条，RL 保持 2,530 条；单次差值从 33.71875 缩小到 20.15625 个百分点。13.5625 个百分点是对这一评分修正规则的敏感程度，不能解释为训练收益中“由格式学习造成的比例”。其余解析边界尚未全部处理，剩余 20.15625 个百分点也不能自动称为纯数学推理提升。最终数值正确仍须与推理步骤正确区分。

其次，Base pass@16 已有明显的天花板。94% 的起点最多允许再提高 6 个百分点，而观察到的 pass@1 增益是 33.71875 个百分点。因此，在原始评分和这些点估计下，即使 RL 的 pass@16 达到 100%，两个增益之差也至少为 27.71875 个百分点。大幅正的端点差值因而受到指标上限约束，不能单独区分“更稳定地输出已有答案”与“推理能力发生变化”。

单次正确率的实测增益、端点关系与机制解释应分别陈述。16 次未答对不等于该模型在任何采样预算下都答不对；仅 RL 覆盖的 5 道题不能据此认定为新能力。按题 bootstrap 只覆盖本次训练结果条件下的评测题不确定性，不包含独立训练种子之间的变化。

## 优先顺序

1. 先完成评分器审查。把重复标记、明确答案前缀、矛盾答案等行为定义清楚，以不读取 gold 的提取规则和正反例回归测试固定新规则。保留原始分数和原始回答。
2. 对同一批 Base/RL 回答采用完全相同的新规则，另存敏感性结果、置信区间和逐题变化。不要只修正 Base，也不要为扩大或缩小增益挑选规则。
3. 同一评分器也参与训练奖励，所以评测重评分不会修复已经发生的优化过程。应检查训练奖励受该错误影响的范围；若要作“修正后的数值奖励 RLVR”主张，需要相应的新训练版本，而不是把旧模型事后改名。
4. 原始 checkpoint-384 是按原评分的开发集选择出来的。若重评开发集，应同时重评全部三个既有候选，另记选择敏感性；保留原冻结选择，不能按最终测试表现挑候选。固定 checkpoint-384 的重评分仍是一项有效的评分敏感性分析。
5. 完成结构题的独立审阅后再开展数值/关系变体比较。当前 `all` 结果尚未检验这部分假设，四个模板家族的区间也应限于探索性结构证据。

当前优先级高于立即启动 4B 或增加训练轮数的是澄清评分协议。后续 4B 可以作为规模对照，但应使用已审计的规则；更大的模型不会自动解决答案提取和 pass@16 天花板问题。

依据：下载的 `main_analysis/report.md` 和 `summary.json`、先前已核对的 proposal 第 1–2 页及本次独立回答质量审查。窄范围重评分的最终数字、源文件身份和规则以同目录的评分敏感性审计文件为准。
